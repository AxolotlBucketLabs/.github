# AxolotlBucketLabs

AxolotlBucketLabs is an open-source organization focused on Axolotl-PM and PocketMine-MP.

We maintain practical server software, reusable PHP libraries, development tooling, and release workflows for the Bedrock server ecosystem. We also help keep useful existing projects compatible with current platforms while preserving their licenses, attribution, and established behavior.

We welcome human contributors and agent-assisted development. Good changes begin with the repository's existing design, explain the problem they solve, and include the checks needed to support them. We prefer small, understandable changes over unnecessary complexity.

Each repository has its own documentation, support channels, contribution rules, and license. Read those materials before using or contributing.

For community discussion, join the [AxolotlBucketLabs Discord](https://discord.gg/Pk4FrNvHnM).
